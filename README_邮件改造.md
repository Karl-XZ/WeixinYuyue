# 微信预约系统邮件改造项目

## 📋 项目概述

本项目将微信小程序预约系统的提醒机制从"订阅消息"改造为"邮件提醒"，实现了更稳定、更可靠的通知方式。

### 改造目标
- ✅ 彻底移除订阅消息机制
- ✅ 教师注册时要求填写邮箱并验证
- ✅ 学生预约成功后立即发送邮件提醒教师

### 改造完成时间
2026年1月16日

## 📧 邮件配置

### 当前配置（163邮箱）
- **SMTP服务器：** smtp.163.com
- **端口：** 465
- **发件邮箱：** your_email@163.com
- **授权码：** your_smtp_auth_code_here

### 更换邮箱
如需更换邮箱，请修改 `cloudfunctions/mcloud/framework/lib/mail_lib.js` 或配置环境变量。

详见：[快速部署指南.md](./快速部署指南.md) 第四章节

## 🔧 核心功能

### 教师注册流程
1. 填写基本信息（姓名、手机、密码、教师密码）
2. 填写邮箱地址
3. 点击"发送验证码"，邮箱收到6位数字验证码
4. 填写验证码并提交注册
5. 注册成功，邮箱已验证

### 学生预约提醒
1. 学生成功预约课程
2. 系统自动读取教师邮箱
3. 立即发送邮件提醒教师
4. 邮件包含：预约项目、时间、学生信息

## ⚠️ 注意事项

### 1. 老教师数据
已有教师数据的邮箱字段为空，不会收到邮件提醒。建议：
- 提供"绑定邮箱"功能
- 或让老教师重新注册

### 2. 邮箱安全
- 定期更换授权码（建议3-6个月）
- 监控异常登录
- 不要将授权码提交到代码仓库

### 3. 发送限制
- 已实现60秒发送限流
- 邮件服务商可能有日发送量限制
- 建议监控发送失败率

## 🐛 常见问题

### Q: npm install 失败？
```bash
# 使用淘宝镜像
npm install --registry=https://registry.npmmirror.com
```

### Q: 邮件发送失败？
1. 检查授权码是否正确
2. 确认163邮箱已开启SMTP服务
3. 查看云函数日志

### Q: 验证码收不到？
1. 检查邮箱地址是否正确
2. 查看垃圾邮件文件夹
3. 查看云函数日志确认是否发送成功

更多问题请查看：[快速部署指南.md](./快速部署指南.md) 第三章节
